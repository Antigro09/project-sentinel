# Instructions for math-findings

Before starting a research cycle anywhere under this directory, read and follow `RESEARCH-PROTOCOL.md` in full.

Keep one numbered topic directory per item in the taxonomy. Put reusable instructions and the index at this root; put each cycle's report, source audit, formal stubs, experiment code, and generated evidence inside its topic directory.

Scientific status rules:

- A paper proof is not a mechanically checked proof.
- A theorem stub is not a formal verification result.
- A toy numerical check is not evidence of AGI capability.
- A bounded literature search cannot establish novelty.
- Use the Sentinel evidence labels and retain negative results, failed assumptions, and retractions.
- Do not edit or overwrite previous cycle reports; create a new cycle directory.
